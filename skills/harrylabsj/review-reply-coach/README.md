# Compliant Review Reply Coach

Professional, tone-calibrated responses to customer reviews — positive, neutral, or negative — across all major platforms.

## Features

- Tone-calibrated response templates for every star rating (1–5★)
- De-escalation framework for angry and emotional reviews
- Positive review amplification to build brand loyalty
- Response policy builder for customer service teams
- Multi-language response generation
- Safety-first: escalates serious complaints appropriately

## Install

```
openclaw skills install harrylabsj/review-reply-coach
```

## Usage

```
帮我想一个回复这条差评：客户说收到的衣服颜色和图片完全不像
这条好评怎么回复可以顺便引导复购？
帮我制定一份电商客服团队的评论回复规范，覆盖各平台
把这条回复翻译成英文和日文版本
```

## Platforms

Amazon, Taobao, JD, Google Reviews, App Store, Play Store, Yelp

## Safety

This skill ONLY generates responses to existing reviews. It NEVER creates fake reviews or suggests review manipulation. All responses maintain professional tone. Safety/legal issues are escalated immediately.
