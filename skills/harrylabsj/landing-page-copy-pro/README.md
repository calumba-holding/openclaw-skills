# Landing Page Conversion Copy Pro

Full landing page copy generation — hero headlines, value props, feature-benefit bridges, social proof, FAQ, and CTA cascade. Built for conversion.

## Features

- Generate complete section-by-section landing page copy from briefs
- Hero section optimizer with 5 headline variants using proven formulas
- Feature-to-benefit translator with emotional hooks
- Social proof formatter: testimonials, stats, and trust signals
- FAQ builder addressing common objections
- CTA hierarchy: primary, secondary, and fallback actions
- Conversion framework built-in (AIDA, PAS, StoryBrand)

## Install

```
openclaw skills install harrylabsj/landing-page-copy-pro
```

帮我写一个落地页文案，产品是TeamFlow远程协作工具，面向50-200人远程团队负责人，目标是获取试用注册

No false claims. No fabricated testimonials or stats. No dark patterns in CTA language. Clear pricing and terms. Recommend A/B testing before launch.
