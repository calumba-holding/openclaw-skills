# Waimai

外卖决策助手 Skill。

它不是账号型下单工具，而是一个公共信息驱动的“现在点哪家更划算”判断器。

它重点帮用户回答：
- 哪家更适合现在点
- 满减到底划不划算
- 配送费和起送价是不是把优惠吃掉了
- 单人餐、双人餐、夜宵、工作餐应该怎么选

## 擅长什么

- 比较多个商家的公开优惠和门槛
- 判断 headline discount 和实际到手成本的差异
- 分析配送费、起送价、套餐结构、活动门槛
- 给出直接建议，而不是只罗列信息

## 不做什么

- 不登录用户账号
- 不访问订单历史
- 不代替用户结算
- 不假装做实时账号态操作

## 适合的请求

- `帮我看看这几家外卖哪家更划算`
- `满减和配送费算下来到底哪家值`
- `一个人吃饭应该点哪家`
- `帮我比较一下几家外卖活动`
