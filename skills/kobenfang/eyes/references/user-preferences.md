# 用户偏好文件

> 本文件记录用户对热点事件监控的个性化偏好。由 eyes skill 自动维护。

## 格式说明

- `lastSeen`：ISO 时间戳，该行业/标的最近一次被用户提及的时间
- `status`：active（活跃）/ dimmed（降权，6个月无提及）
- 超过 180 天（6个月）未提及 → 自动从列表移除
- 90-180 天未提及 → 降权标记（排在末尾，标注 ⚠️）
- 每次被提及 → 重置 lastSeen 为当前时间，status 恢复 active

## 衰减规则

| 条件 | 动作 |
|------|------|
| 某行业/标的距上次提及 ≤ 90 天 | 保持 active，正常参与加权 |
| 90 天 < 距上次提及 ≤ 180 天 | 降权，标注 ⚠️，排在列表末尾 |
| 超过 180 天未提及 | 自动从列表移除 |

## 清理时机

早 8 点汇总任务（eyes-morning）末尾执行偏好清理，不额外增加定时任务。
