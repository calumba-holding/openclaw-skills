# Mcqueen

## 历史时间线

- **1992年** — Lee Alexander McQueen从中央圣马丁毕业展成名
- **1996年** — 被Givenchy任命为创意总监
- **2000年** — Gucci（后Kering）收购McQueen品牌51%股份
- **2001年** — 首场标志性大秀'Voss'（精神病院主题）
- **2010年2月** — Lee Alexander McQueen去世，享年40岁
- **2010年** — Sarah Burton接任创意总监
- **2023年** — Seán McGirr接任创意总监

## 商业模式

高级成衣（男女装）、皮具（骷髅头丝巾是标志性产品）、鞋履（夸张厚底鞋是畅销品）、配饰。Kering集团提供全球零售网络支持。品牌定位在高端奢侈与先锋设计之间。

## 护城河分析

Lee McQueen的传奇设计师声誉（时尚史级别的创意天才）；骷髅头丝巾的标志性地位（长期畅销品）；Kering集团的资源和渠道支持；在先锋时尚与商业奢侈之间的独特定位。

## 关键数据

Kering集团全资控股；全球约200家门店；年营收估计约5-7亿欧元；Sarah Burton任职13年后于2023年离任

## 有趣事实

- Lee McQueen的毕业设计被Isabella Blow全部买下，后者成为他的导师和缪斯。
- McQueen的自杀被视为时尚界最大的悲剧之一，他去世时品牌正处于商业巅峰。
