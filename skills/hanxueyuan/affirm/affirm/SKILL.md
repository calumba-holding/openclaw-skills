# Affirm

## 历史时间线

- **2012年** — PayPal联合创始人Max Levchin在旧金山创立Affirm
- **2014年** — 首家合作商家上线
- **2018年** — 与Amazon达成合作，成为其BNPL服务商
- **2021年** — 纳斯达克上市（股票代码AFRM），首日市值超100亿
- **2023年** — 推出Affirm Card（借记卡）和储蓄账户
- **2024年** — GMV超250亿美元，合作商户超30万家

## 商业模式

BNPL核心：消费者在结账时选择分期（0%或低利率），Affirm向商家收取2-8%佣金。与传统信用卡不同：无隐藏费用、无复利、无滞纳金。收入来源：商家佣金（主要）+ 消费者利息 + 会员卡（Affirm Card）收入。Shopify和Amazon是关键合作伙伴。

## 护城河分析

技术：实时信用决策引擎，使用替代数据评估信用，覆盖传统信用评分无法触及的人群。透明度：'无隐藏费用'的品牌定位在年轻消费者中极具吸引力。商户网络：30万+商户形成双边网络效应。创始团队：PayPal早期核心成员，支付行业经验深厚。

## 关键数据

2024年GMV超250亿美元；合作商户超30万家；2024财年收入约23亿美元；活跃消费者超1,800万；市值约150亿美元。

## 有趣事实

- Affirm的创始人Max Levchin是PayPal最早的工程师之一，也是PayPal'PayPal黑帮'的核心成员
- Affirm是第一个在火箭发射中投放广告的金融科技公司——2022年SpaceX发射时打出了一条横幅
