# Go Pro

## 历史时间线

- **2002年**：Nick Woodman冲浪旅行后，用35毫米胶片相机绑在手腕上，产生运动相机构想
- **2004年**：在圣迭戈创立GoPro，首款产品使用35毫米胶片
- **2006年**：推出第一款数码相机HERO
- **2014年**：GoPro上市，IPO估值$30亿
- **2016-2018年**：智能手机摄影进步导致销量暴跌，股价下跌超80%
- **2020年**：推出HERO9，凭借超宽镜头和Hindsight功能复苏
- **2024年**：转型订阅模式，硬件+云存储+编辑软件一体化

## 商业模式

运动相机硬件销售 + 订阅服务（GoPro Subscription）。订阅包含云存储、设备替换保障、编辑工具。年收入约$10亿，订阅用户数百万。产品覆盖HERO系列、MAX全景相机等。

## 护城河分析

品牌在极限运动文化中的心智占领，硬件与软件+云的闭环生态，丰富的配件系统和用户生成内容(UGC)社区，与红牛等运动品牌的深度合作。

## 关键数据

2002年创立，2014年上市(IPO $30亿)，年收入约$10亿，曾股价暴跌80%后复苏

## 有趣事实

GoPro创始人的第一台原型机是用冲浪腰带和35毫米柯达相机用橡皮筋绑在一起的——价值$35的设备后来变成了一家市值曾超$30亿美元的上市公司。
