# Atari

Atari — 电子游戏产业的奠基者，从 Pong 的街机革命到 1983 年美国游戏业大崩溃，再到今天的品牌遗产

## 历史时间线

- 1972 — Nolan Bushnell 和 Ted Dabney 创立 Atari（源自围棋术语'将军'）
- 1972 — 发布 Pong，街机游戏革命的开始
- 1977 — 推出 Atari 2600 家用游戏机
- 1980 — 《Adventure》发布——第一个包含 Easter Egg 的电子游戏
- 1982 — Atari 收入 $2B（占 Warner Communications 的 50%）
- 1983 — 《E.T.》游戏滞销，导致美国游戏业大崩溃
- 1984 — 电脑游戏部门被卖给 Jack Tramiel（Commodore 创始人）
- 2013 — 申请破产保护
- 2018 — 推出 Atari VCS 复古游戏机

## 商业模式

游戏开发 + 复古硬件（Atari VCS）+ 品牌授权 + 酒店和赌场（Atari 品牌酒店）。Atari 目前主要依靠品牌 IP 价值和怀旧经济。

## 护城河分析

Atari 品牌在游戏文化中的标志性地位——Pong 和 2600 是电子游戏历史的起点；庞大的复古游戏 IP 库（超过 300 款经典游戏）。

## 关键数据

1982 年营收 $2B（占 Warner 总收入的 50%）；Atari 2600 总销量超过 3,000 万台；E.T. 游戏滞销导致 350 万份卡带被掩埋在新墨西哥州。

## 有趣事实

- 2014 年，新墨西哥州阿拉莫戈多的垃圾填埋场被挖掘，确实发现了当年被掩埋的 130 万份 E.T. 游戏卡带——这是互联网传说变成考古发现。
- Atari 的名字源自围棋术语'アタリ'（将军/叫吃）——Nolan Bushnell 在日本旅行时学会了围棋并选择了这个名字。
