# On Running

## 历史时间线

- **2010年** — Olivier Bernhard等三位创始人在苏黎世创立On
- **2013年** — Cloudrunner在FISCHER渠道首发
- **2018年** — Roger Federer投资并成为合伙人
- **2019年** — 进入美国市场
- **2020年** — 纽约证券交易所上市（ONON）
- **2021年** — 推出Cloudmonster，拓展生活方式市场
- **2023年** — 年营收突破18亿瑞士法郎

## 商业模式

跑鞋是核心（Cloud系列），扩展至徒步鞋、网球鞋（与费德勒合作）、运动服装。CloudTec中底技术（中空'Cloud'模块）是差异化核心。DTC+批发双渠道。

## 护城河分析

CloudTec中底技术的视觉辨识度（独特的'鞋底洞'设计）；瑞士工程的品牌定位（精度、品质）；Roger Federer的品牌背书和产品设计参与；DTC渠道占比高（约45%），毛利更好。

## 关键数据

2023年营收约18亿瑞士法郎；全球约35个市场有售；DTC占比约45%；费德勒持有股份并参与产品设计

## 有趣事实

- 三位创始人中有两位是前职业铁人三项运动员。
- CloudTec的灵感来自'在云端奔跑'的感觉，中空模块在着地时压缩、离地时锁定。
