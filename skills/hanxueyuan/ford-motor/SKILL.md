# Ford Motor

## 概览

福特汽车——流水线生产的发明者、美国汽车工业的象征，从 Model T 到 F-150 到电动 Mustang Mach-E 的百年创新史。

## 历史时间线

- 1903: 亨利福特在底特律创立福特汽车
- 1908: Model T 发布——第一款面向大众的量产汽车
- 1913: 引入移动装配线，将 Model T 生产时间从 12 小时缩短至 93 分钟
- 1914: 推出 5 美元日薪（当时行业平均的 2 倍），引发劳工革命
- 1948: F 系列皮卡发布，后来成为 F-150
- 1964: Mustang 发布——开创 Pony Car 细分市场
- 2006: Alan Mulally 出任 CEO，带领公司度过金融危机（唯一未接受政府救助的美国车企）
- 2021: F-150 Lightning 电动皮卡发布
- 2024: 拆分 Ford Blue（燃油）和 Ford Model e（电动）两大业务

## 商业模式

三大板块：Ford Blue（传统燃油车，利润奶牛）、Ford Model e（电动车，高速增长但亏损）、Ford Pro（商用车队服务，高利润率订阅模式）。F 系列皮卡是核心利润来源——在美国皮卡市场持续 40+ 年销量第一。

## 护城河分析

F-150 的品牌忠诚度和市场规模——美国最畅销车型 40+ 年，消费者惯性极强；Ford Pro 商用车服务网络——从车辆到车队管理软件的完整解决方案；百年制造的工艺积累和供应链关系；蓝领文化的品牌认同。

## 关键数据

2023 年营收约 1760 亿美元；F 系列年销量约 75 万辆（美国）；Ford Pro 部门营收超过 550 亿美元；全球员工约 17 万；F-150 Lightning 是电动皮卡销量第二。

## 有趣事实

- 亨利福特 1914 年推出的 5 美元日薪不仅仅是高薪——公司同时雇佣了社会工作者，确保员工的私人生活符合道德标准。
- 福特公司曾在二战期间 Willow Run 工厂每 63 分钟生产一架 B-24 轰炸机——将汽车流水线技术用于军事生产。
