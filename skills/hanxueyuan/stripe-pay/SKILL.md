# Stripe Pay

## 历史时间线
- 2010: 爱尔兰兄弟 Patrick 和 John Collison 在旧金山创立 Stripe
- 2011: Y Combinator 孵化，首版 API 发布
- 2014: Stripe Checkout 简化商户集成
- 2016: Stripe Atlas 帮助全球创业者在美国注册公司
- 2018: 推出 Stripe Terminal，进军线下支付
- 2020: 疫情期间电商爆发，估值达 360 亿美元
- 2021: 估值达 950 美元峰值，后回调至 500 亿
- 2023: 恢复增长，估值约 650 亿美元，准备 IPO

## 商业模式
Stripe 的商业模式是'为互联网经济提供支付和金融基础设施'。收入来自交易手续费（约 2.9% + 30¢/笔），并向企业提供增值服务：Stripe Billing（订阅计费）、Connect（市场支付）、Radar（反欺诈）、Tax（税务合规）、Treasury（银行服务）。核心优势是将复杂的支付合规、清算、多币种转换封装为几行代码的 API。

## 护城河分析
开发者体验：Stripe 的 API 文档被公认为行业标杆；全球覆盖：支持 135+ 种货币和数十种本地支付方式；合规能力：在 47+ 个国家/地区获得支付牌照，这是极高的监管门槛；产品迭代速度：每季度推出新产品和功能，远超传统支付公司

## 关键数据
2023 年营收约 140+ 亿美元（估计）；处理支付量超 1 万亿美元；估值约 650 亿美元（2023 年二级市场）；服务数百万企业（从初创到 Fortune 500）；员工约 8,000+ 人

## 有趣事实
Stripe 的创始人 Patrick Collison（19 岁）和 John Collison（22 岁）在 2010 年创立公司时，是为了简化当时需要数周才能集成的支付系统。他们在 7 行代码中完成了 Stripe API 的初次集成。
