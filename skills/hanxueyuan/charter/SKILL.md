# Charter

Charter Communications (Spectrum) — 美国第二大有线电视运营商和第三大宽带提供商，服务超过3200万用户。

## 历史时间线

- 1993年 — Charter Communications 成立
- 1999年 — 纳斯达克上市
- 2009年 — 申请破产保护后重组
- 2015年 — 宣布以787亿美元收购时代华纳有线
- 2016年 — 完成合并，更名为 Charter Communications
- 2016年 — 推出 Spectrum 品牌
- 2021年 — 订阅用户突破3200万

## 商业模式

通过Spectrum品牌提供有线电视、宽带互联网和移动通信三位一体服务。核心收入来自住宅和企业宽带订阅，利用同轴电缆和光纤混合网络覆盖1900万家庭

## 护城河分析

最后一英里基础设施 — 拥有覆盖美国41个州的大规模有线网络，新竞争者需要巨额资本投入才能复制物理网络覆盖

## 关键数据

- **市值**: 约400亿美元
- **年收入**: 约215亿美元
- **住宅客户**: 约3200万
- **覆盖范围**: 美国41个州，4400万潜在家庭

## 有趣事实

- Charter收购时代华纳有线时创下了美国电信行业最大并购案之一的纪录，交易规模达787亿美元。
- Spectrum Mobile 使用 Verizon 网络 + 自有 WiFi，这种混合模式降低了运营成本。
