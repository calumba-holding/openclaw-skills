# acong-layout-demo

Kitchen-sink SKILL.md demonstrating the full recommended skill directory layout — multi-file progressive disclosure (FORMS.md + REFERENCE.md), a `references/` subfolder with deep docs, a `scripts/` subfolder with executable helpers, and an `assets/` subfolder with templates. Use when you need a reference implementation for authoring complex Claude Code / ClawHub skills, or when validating a skill loader's ability to handle nested directories.

## Install

```bash
# via clawhub
clawhub install acong-layout-demo

# via skills.sh
npx skills add acong-tech/skill-acong-layout-demo
```
