# Lead Magnet Creator

Lead-Magnets erstellen, die konvertieren.

## Features

- ✅ **PDF-Guides** - Professionelle Checklisten, Anleitungen, Templates
- ✅ **Landing Pages** - Next.js kompatibel
- ✅ **E-Mail-Opt-in** - Integration vorbereitet
- ✅ **DACH-optimiert** - Deutsche & englische Inhalte

## Lead-Magnet-Typen

| Typ | Beschreibung |
|-----|--------------|
| **Checkliste** | Kurze, actionable Schritte |
| **Guide** | Ausführliche Anleitung (5-10 Seiten) |
| **Template** | Fertige Vorlagen zum Ausfüllen |
| **Calculator** | Interaktive Rechner |
| **Report** | Daten & Analysen |

## Verwendung

```
Erstelle einen Lead-Magnet für [THEMA].

Zielgruppe: [B2B/B2C]
Format: [PDF-Guide/Checkliste/Template]
Ziel: [E-Mail-Liste aufbauen]
```

## Beispiele

- "KI-Automation Quickstart Guide"
- "SEO-Checkliste für E-Commerce"
- "Lead-Generierung Templates"
- "Content-Kalender 2026"
