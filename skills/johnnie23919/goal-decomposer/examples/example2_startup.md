# 示例2：创业计划拆解

## 输入目标
"开一家咖啡店"

## 输出任务树

```
目标：开设咖啡店
├─ T1: 市场调研 [P0] [估算: 2周]
│  ├─ 1.1 竞品分析
│  │  ├─ 周边3公里咖啡店调研
│  │  ├─ 星巴克/瑞幸/独立咖啡馆对比
│  │  └─ 价格区间分析
│  ├─ 1.2 目标客户画像
│  │  ├─ 年龄段：25-45岁白领
│  │  ├─ 消费能力：日均30-50元
│  │  └─ 需求场景：商务洽谈/社交/外带
│  └─ 1.3 定位决策
│     ├─ 风格：文艺简约/商务高端
│     └─ 产品线：精品咖啡+轻食
│
├─ T2: 选址与装修 [P0] [估算: 1-2月]
│  ├─ 2.1 选址考察
│  │  ├─ 人流量统计（工作日/周末）
│  │  ├─ 租金预算评估
│  │  └─ 停车便利性
│  ├─ 2.2 装修设计
│  │  ├─ 设计风格确定
│  │  ├─ 装修公司比价
│  │  └─ 施工周期规划
│  └─ 2.3 证照办理
│     ├─ 营业执照
│     ├─ 食品经营许可证
│     └─ 消防验收
│
├─ T3: 设备与供应链 [P0] [估算: 2周]
│  ├─ 3.1 核心设备采购
│  │  ├─ 意式咖啡机：La Marzocco/Slayer
│  │  ├─ 磨豆机：Mazzer
│  │  └─ 其他设备：冰箱/制冰机/收银系统
│  ├─ 3.2 咖啡豆供应链
│  │  ├─ 烘焙商选择
│  │  ├─ 试喝与定价
│  │  └─ 签订供应协议
│  └─ 3.3 其他物料
│     ├─ 杯具/吸管/包装
│     └─ 清洁用品
│
├─ T4: 团队组建 [P1] [估算: 1月]
│  ├─ 4.1 招聘计划
│  │  ├─ 店长：1人
│  │  ├─ 咖啡师：2-3人
│  │  └─ 兼职：2人
│  ├─ 4.2 培训体系
│  │  ├─ 咖啡制作培训
│  │  └─ 服务流程培训
│  └─ 4.3 薪酬制度
│     ├─ 基本工资+提成
│     └─ 社保公积金
│
├─ T5: 营销推广 [P1] [估算: 持续]
│  ├─ 5.1 开业活动
│  │  ├─ 试营业（1周）
│  │  └─ 正式开业促销
│  ├─ 5.2 线上营销
│  │  ├─ 小红书/抖音推广
│  │  ├─ 大众点评入驻
│  │  └─ 微信社群运营
│  └─ 5.3 会员体系
│     ├─ 积分制度
│     └─ 储值优惠
│
└─ T6: 财务规划 [P0] [估算: 1周]
   ├─ 6.1 启动资金预算
   │  ├─ 租金押金：3-6个月
   │  ├─ 装修：10-20万
   │  ├─ 设备：8-15万
   │  └─ 流动资金：5-10万
   ├─ 6.2 运营成本预估
   │  ├─ 月租金：1-3万
   │  ├─ 人力成本：2-4万/月
   │  └─ 原材料：营业额30%
   └─ 6.3 盈亏平衡分析
      └─ 日均销售目标：80-120杯
```

## 关键数据
- **总投资**：30-50万
- **回本周期**：12-18个月
- **日均目标**：80-120杯
- **毛利率**：65-70%

## 风险提示
1. 选址是成败关键（占成功因素60%）
2. 租金占比控制在营业额20%以内
3. 前3个月现金流压力大
