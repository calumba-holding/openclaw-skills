# 示例1：产品规划拆解

## 输入目标
"做一个AI写作工具"

## 输出任务树

```
目标：开发AI写作工具
├─ T1: 市场调研 [P0] [估算: 1周]
│  ├─ 1.1 竞品分析
│  │  ├─ Notion AI：定位协作写作
│  │  ├─ Jasper：营销文案导向
│  │  └─ Copy.ai：快速生成工具
│  ├─ 1.2 用户痛点收集
│  │  ├─ 调研问卷设计
│  │  └─ 访谈5-10位目标用户
│  └─ 1.3 市场定位决策
│     ├─ 选择细分场景（如学术写作/商业文案）
│     └─ 定义核心差异化价值
│
├─ T2: 产品设计 [P0] [估算: 2周]
│  ├─ 2.1 功能清单
│  │  ├─ 核心功能：文本生成、润色、改写
│  │  ├─ 增值功能：多语言、模板库、协作
│  │  └─ MVP范围确定
│  ├─ 2.2 用户故事编写
│  │  └─ 5-10个核心用户故事
│  └─ 2.3 交互原型设计
│     ├─ 线框图
│     └─ 高保真原型
│
├─ T3: 技术实现 [P0] [估算: 4周]
│  ├─ 3.1 架构选型
│  │  ├─ 后端：Node.js + Express
│  │  ├─ 前端：React + TypeScript
│  │  └─ AI接口：OpenAI/Claude API
│  ├─ 3.2 核心功能开发
│  │  ├─ 文本生成模块
│  │  ├─ 提示词模板系统
│  │  └─ 用户认证系统
│  └─ 3.3 测试与优化
│     ├─ 单元测试
│     └─ 性能优化
│
└─ T4: 上线运营 [P1] [估算: 持续]
   ├─ 4.1 部署上线
   │  ├─ 服务器部署
   │  └─ 域名+SSL配置
   ├─ 4.2 用户获取
   │  ├─ SEO优化
   │  └─ 社交媒体推广
   └─ 4.3 迭代优化
      ├─ 用户反馈收集
      └─ 功能迭代规划
```

## 关键洞察
1. **前置依赖**：T1完成才能做T2决策
2. **并行可能**：T1.1和T1.2可并行
3. **风险点**：AI API成本控制
4. **MVP范围**：建议先实现T1+T2+T3核心部分

## 执行建议
- 第1-2周：完成T1市场调研
- 第3-4周：完成T2产品设计
- 第5-8周：完成T3技术实现
- 第9周+：T4持续运营
