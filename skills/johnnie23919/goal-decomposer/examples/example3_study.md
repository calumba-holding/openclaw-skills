# 示例3：学习计划拆解

## 输入目标
"准备研究生考试（计算机专业）"

## 输出任务树

```
目标：通过研究生入学考试
├─ T1: 信息收集与规划 [P0] [估算: 2周]
│  ├─ 1.1 院校选择
│  │  ├─ 目标院校清单（3-5所）
│  │  ├─ 分数线调研（近3年）
│  │  └─ 报录比分析
│  ├─ 1.2 考试科目确认
│  │  ├─ 政治（100分）
│  │  ├─ 英语一/二（100分）
│  │  ├─ 数学一/二（150分）
│  │  └─ 专业课（150分）
│  └─ 1.3 学习计划制定
│     ├─ 时间分配：数学40%、专业课30%、英语20%、政治10%
│     └─ 阶段划分：基础→强化→冲刺
│
├─ T2: 数学备考 [P0] [估算: 6个月]
│  ├─ 2.1 基础阶段（3-6月）
│  │  ├─ 高等数学：极限、导数、积分
│  │  ├─ 线性代数：矩阵、向量空间
│  │  └─ 概率论：随机变量、分布
│  ├─ 2.2 强化阶段（7-9月）
│  │  ├─ 刷题训练
│  │  └─ 真题精练
│  └─ 2.3 冲刺阶段（10-12月）
│     ├─ 模拟考试
│     └─ 查漏补缺
│
├─ T3: 专业课备考 [P0] [估算: 5个月]
│  ├─ 3.1 参考书目
│  │  ├─ 数据结构（严蔚敏）
│  │  ├─ 计算机组成原理（唐朔飞）
│  │  ├─ 操作系统（汤子瀛）
│  │  └─ 计算机网络（谢希仁）
│  ├─ 3.2 知识点梳理
│  │  ├─ 思维导图制作
│  │  └─ 重难点笔记
│  └─ 3.3 真题训练
│     ├─ 近10年真题
│     └─ 错题整理
│
├─ T4: 英语备考 [P1] [估算: 持续]
│  ├─ 4.1 单词积累
│  │  ├─ 每日50词
│  │  └─ 总量：5500词
│  ├─ 4.2 阅读训练
│  │  ├─ 真题阅读精练
│  │  └─ 长难句分析
│  ├─ 4.3 作文准备
│  │  ├─ 模板整理
│  │  └─ 练习20篇
│  └─ 4.4 翻译训练
│     └─ 真题翻译练习
│
└─ T5: 政治备考 [P2] [估算: 3个月]
   ├─ 5.1 基础阶段（9-10月）
   │  ├─ 马原、毛概、史纲、思修
   │  └─ 网课+笔记
   ├─ 5.2 强化阶段（11月）
   │  ├─ 1000题刷题
   │  └─ 错题本整理
   └─ 5.3 冲刺阶段（12月）
      ├─ 时政热点
      ├─ 模拟卷训练
      └─ 背诵肖四肖八
```

## 时间分配建议
```
总学习时间：6-8个月
每日学习：8-10小时

时间段分配：
├─ 早上（2h）：英语单词+阅读
├─ 上午（3h）：数学
├─ 下午（3h）：专业课
├─ 晚上（2h）：政治/复习
└─ 睡前（1h）：回顾总结
```

## 资源推荐
- **数学**：张宇/汤家凤网课
- **英语**：恋恋有词、真题
- **专业课**：王道论坛、真题
- **政治**：肖秀荣、徐涛

## 关键节点
- 6月底：数学基础完成
- 9月底：强化阶段完成
- 11月底：真题刷完
- 12月：冲刺模拟
