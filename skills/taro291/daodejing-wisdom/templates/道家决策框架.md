# 道家决策框架

## 一、问题界定

### 1.1 核心问题
- 问题本质是什么？
- 问题背后的自然趋势是什么？
- 是否违背了自然规律？

### 1.2 问题层次
```
表象问题 → 深层矛盾 → 根本趋势
    ↓           ↓           ↓
  症状       原因       规律
```

## 四、柔弱策略

### 4.1 以柔克刚四法

| 策略 | 适用场景 | 具体做法 |
|------|---------|---------|
| **示弱** | 面对强势对手 | 隐藏锋芒，让对手放松 |
| **借力** | 资源不足时 | 借势借力，四两拨千斤 |
| **韧性** | 长期博弈 | 持续积累，不急不躁 |
| **退让** | 陷入僵局 | 以退为进，留有余地 |

### 4.2 水德应用
- **利万物而不争**：创造价值，不争功
- **处众人之所恶**：做别人不愿做的事
- **善利万物**：帮助他人成功
- **动静皆有时**：把握进退时机

## 五、辩证考量

### 5.1 祸福转化分析

```
        当前处境
           ↓
    ┌──────┴──────┐
    ↓             ↓
  利的一面       弊的一面
    ↓             ↓
过度发展的隐患   转化的契机
    ↓             ↓
  ┌──┴──┐       ┌──┴──┐
  祸→福  福→祸   祸→福  福→祸
```

### 5.2 辩证思考清单
- [ ] 这件事的好处可能带来什么隐患？
- [ ] 这件事的坏处可能蕴含什么机会？
- [ ] 物极必反的临界点在哪里？
- [ ] 如何避免"知止不殆"？

### 5.3 经典辩证法则
| 矛盾对子 | 转化关系 | 应用 |
|---------|---------|------|
| 祸 ↔ 福 | 祸兮福所倚，福兮祸所伏 | 顺境防患，逆境寻机 |
| 有 ↔ 无 | 有之以为利，无之以为用 | 重视无形价值 |
| 曲 ↔ 全 | 曲则全，枉则直 | 委曲求全 |
| 弱 ↔ 强 | 柔弱胜刚强 | 以柔克刚 |

## 六、谦下之道

### 6.1 处下策略
| 场景 | 谦下做法 | 预期效果 |
|------|---------|---------|
| 领导团队 | 示弱求助，成就他人 | 团队凝聚力 |
| 谈判博弈 | 承认不足，请教对方 | 降低戒备 |
| 处理冲突 | 先承认己方问题 | 化解对立 |
| 获取资源 | 承认需要帮助 | 获得支持 |

### 6.2 不争之争
```
不争功 → 功归于你
不争利 → 利聚于你
不争名 → 名附于你
不争高 → 高成于你
```

## 八、执行与复盘

### 8.1 执行原则
- **顺其自然**：不强行推进
- **适时而动**：等待最佳时机
- **留有余地**：不过度透支
- **知足常乐**：适可而止

### 8.2 复盘要点
- [ ] 是否遵循了自然规律？

- [ ] 是否体现了柔弱智慧？
- [ ] 是否看清了祸福转化？
- [ ] 是否实践了谦下之道？
